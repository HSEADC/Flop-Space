## Основное 
- Подогнали под актуальный дизайн (в процессе доработки и наполнения)
- В процессе занесения всех компонентов
- CSS классы по методологии БЭМ
- Наша дизайн-система со всеми составляющими полностью занесена 
- Дев-режим вебпака настроен и правильно работает, используется HMR
---
## Управление иконками 
- Иконки добавляются на страницы через svg-sprite-loader
- Все иконки читаются скриптом из папки src/icons и автоматически добавляются в сборку
- Добавляем иконки в html через href по прямому названию из файла
---
## Как быстро управлять контентом? (Работает на главной для карточек)
- Заходим в content.json 
- Добавляем новый массив со значениями (title, subtitle и тд.) и заполняем его, указываем тип карточки статьи (card-medium или card-default), порядок отрисовки (position)
- если добавляем две медиум-карточки подряд, они кладутся в отдельный контейнер и располагаются горизонтально, если в массиве идёт больше двух карточек подряд, то третья положится в отдельный контейнер, лучше сразу же добавлять четвертую такую карточку, таким образом мы получим два горизонтальных контейнера с карточками подряд
